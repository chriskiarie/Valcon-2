# Source assets

This folder keeps originals and internal working material out of the deployed site. Nothing here is served by Next.js.

## Folders

- `brand/` — logo files, brand fonts, colour references and other material supplied by the client. Pending.
- `photos-raw/` — original photography. Large files are ignored by Git and must never be deployed directly.
- `video-raw/` — original video. Large files are ignored by Git and must never be deployed directly.
- `reference/` — internal screenshots for structure reference only (Phoenix Aviation and Karak & Go). Do not copy their text, images, code or colours. Folder contents are ignored by Git.

Only optimised, web-ready derivatives belong in `site/public`. Record any demo stock photography in `../docs/asset-log.md`.
